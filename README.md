# Note-to-Quiz Learning App

## Project Overview

The **Note-to-Quiz Learning App** is an AI-powered platform that transforms your raw notes into personalized quizzes. Designed primarily for high school and college students, this app helps users remember more in less time using adaptive quizzing powered by natural language processing and spaced repetition algorithms.

### Value Proposition

- Turn lecture notes, PDFs, and other texts into interactive quizzes quickly.
- Personalized, adaptive quizzing tailored to your strengths and weaknesses.
- Multiple quiz modes, including practice, test, and spaced repetition.
- Dashboard analytics to track progress and identify weak spots.

## Features (Phases 1 & 2)

- Text input for notes via typing, pasting, or uploading PDFs.
- AI-powered quiz generation: MCQs, flashcards, fill-in-the-blank, true/false.
- Adaptive spaced repetition engine (SM2 algorithm) for scheduling reviews.
- Interactive quiz-taking UI with immediate feedback.
- Performance dashboard with charts showing progress, accuracy, and weak spots.
- Responsive, accessible, and mobile-friendly design.
